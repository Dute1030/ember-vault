# 六条职业构筑路线

更新日期：2026-09-11。源码同步至 GitHub；线上部署状态独立。

本次沿用 60 张卡及白／紫／金概率，重做其中 16 张的条件收益，调整淬毒及蛇神之牙。流派不锁职业分支、不限制抓牌；允许有配合的混合构筑，但裸抓终结牌的收益下降。

| 职业 | 流派 | 启动与收益 | 主要取舍 |
| --- | --- | --- | --- |
| 铁卫 | 蓄甲盾击 | 格挡、壁垒、固守蓄甲 → 盾击 / 钢铁意志抽牌 → 熔炉重拳输出 | 重拳清空防御；抽牌需要出牌前至少 10 护甲 |
| 铁卫 | 血铸反攻 | 血铸 / 血誓铸甲支付生命 → 战意力量、背水列阵伤害、钢铁行军防御、重整旗鼓抽牌 | 本回合卡牌支付至少 3 生命；换回合清零，敌人伤害不算 |
| 影刃 | 叠毒引爆 | 淬毒 + 无声蔓延 → 毒雾续毒、以毒为幕防御 → 毒囊破裂 | 目标已有 5 层毒才有额外收益；引爆消耗全部毒层 |
| 影刃 | 连击收割 | 快刃 / 潜行 / 刃舞 → 牵丝刃续抽、烟中换位防御 → 终结 | 先打两张启动牌；高费杂牌会打断节奏，Boss 第四张惩罚仍在 |
| 秘术师 | 蓄能爆发 | 冥想 / 引流蓄能 → 彗星爆发或折光结界防御 | 至少 4 灵力才触发额外收益；两种终结方式争夺同一资源 |
| 秘术师 | 寒霜压制 | 寒霜 → 符文屏障、环星术 → 蚀日咒 | 目标已有 2 回合虚弱才触发；敌人行动会让虚弱减少 |

## 具体调整

- 钢铁意志：7 护甲、抽 1；出牌前至少 10 护甲时再抽 1。盾击满足相同条件时抽 1。钢铁蓄势专精添加消耗，避免免费返能补牌反复循环。
- 战意：基础 1 力量，血铸条件额外 2。背水列阵：以血铸条件额外 7 伤害代替原半血奖励。钢铁行军：以血铸条件额外 6 护甲代替通用连出增伤。重整旗鼓：回血 5、护甲 4，血铸条件额外抽 2。
- 铁卫初始牌组用一张血铸替换一张斩击，仍为 10 张；两种方向从开局就能尝试。
- 淬毒由 5 毒调整为 4；蛇神之牙由额外 2 毒调整为 1。以毒为幕为 3 护甲、1 毒，满足毒层条件额外 4 护甲。毒雾基础 5 毒，满足条件的目标额外 3 毒。
- 牵丝刃：基础 3 伤害，每张已出牌加 2（上限计算 3 张）；连击条件额外抽 1。终结基础 14，连击后 22。烟中换位基础抽 1、护甲 4；连击条件额外抽 1、护甲 3。
- 彗星基础 16 伤害，蓄能条件额外 8，灵力仍每层加 3 并消耗。折光结界在蓄能条件下额外抽 1。
- 符文屏障基础 7 护甲，寒霜条件额外 4，改为选择敌人判断条件，护甲仍给予自己。环星术基础 5 伤害、1 灵力，寒霜条件额外 2 灵力。蚀日咒基础群伤 8、虚弱 1，满足条件的敌人额外受到 8 伤害。

所有条件均在出牌前检查。群攻逐个检查目标，不能借用其他敌人的毒或虚弱。本张牌施加的状态不能反过来触发本张牌奖励。强化和专精继承条件，个别专精会改变启动方式，需要看升级预览。

## 界面与兼容

职业选择页和顶部“流派指南”展示两条路线、启动／收益牌、取舍及当前牌组数量。卡牌有流派标签，奖励与商店列出现有相关牌；战斗手牌显示条件是否满足，目标预览包含自身护甲和灵力变化。

旧存档继续可读；缺失的本回合血铸计数视为零。旧牌组不会被替换，已有卡牌使用更新后的效果。新开局才使用新的铁卫初始牌组。

## 验证与局限

96 项测试覆盖六条真实出牌链、顺序、条件阈值、目标隔离、群攻、回合重置、致死生命代价、保存恢复，以及既有战斗和经济规则。完成类型检查与生产构建。

本次模拟加入可选的两步出牌预判，以及两条流派各自的抓牌偏好。三种策略使用同一批种子 5000–5059，每职业每难度 60 局。结果附于 `archetype-balance-results.json`；不同策略不是不同玩家群体，重复种子也不是独立样本。两步预判比旧版单步策略更强，因此不能把本次结果与旧版约 20% 的模拟直接比较，也不保证真人通关率。构筑指南的卡牌数量不是成型判定，混合构筑仍可能表现更好。

复现命令：

```bash
SIM_RUNS=60 SIM_START=5000 SIM_BUILD=1 SIM_LOOKAHEAD=1 node tests/simulate.ts
SIM_RUNS=60 SIM_START=5000 SIM_BUILD=2 SIM_LOOKAHEAD=1 node tests/simulate.ts
SIM_RUNS=60 SIM_START=5000 SIM_LOOKAHEAD=1 node tests/simulate.ts
```

六条路线均可通关，但表现并不完全相等：当前策略下铁卫混合构筑与秘术师寒霜路线较强，血铸在苦难模式更有风险。不能据此声称已达到所有职业统一约 20% 通关率；后续平衡应结合真人记录继续调整。
